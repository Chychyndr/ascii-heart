# OpenGL ASCII Heart

Красивое 3D-сердце из ASCII-символов в отдельном OpenGL-окне.

Есть вращение, красный градиент, плавное появление и эффект сердцебиения.

## Запуск

```powershell
uv run ascii_heart.py
```

`uv` сам установит зависимости из блока в начале файла.

## Управление

```text
Esc    закрыть окно
Space  пауза / продолжить
```

## Файл

Основной скрипт:

```text
ascii_heart.py
```

## Требования

- Python 3.10+
- uv
- рабочий OpenGL-драйвер
